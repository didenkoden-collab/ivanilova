# 📚 Трекер прочитанных книг

Консольное приложение для отслеживания прочитанных книг с сохранением данных в JSON.

## 🚀 Возможности

- Добавление книг (автор, название, оценка, дата прочтения)
- Просмотр всех книг
- Расчёт средней оценки
- Статистика по авторам
- Удаление книг
- Защита от дубликатов
